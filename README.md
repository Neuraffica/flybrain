# flybrain

Starter kit for **Fly Brain & Tiny Machines**, a one-day BioCompute hackathon by [Neuraffica](https://neuraffica.com) in Berkeley, CA (Dec 5, 2026).

The challenge: use the *Drosophila* (fruit fly) connectome to build small, efficient AI for edge devices.
