Offline benchmark

An infrared proximity sensor stands in for the fly's eye: each of its two channels reads high with nothing in front and drops as a hand comes close, only over a narrow band of distances. All five models get the same two numbers at every reading; only the driver moves the robot. While the robot backs away the sensor is not read (a read would stop the walk), so the trace has a gap.
