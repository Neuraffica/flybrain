Bittle simulator artwork — verification, 2026-11-15

Technique and provenance
Offline Blender/Cycles renders of Petoi's articulated Bittle geometry, with
black/yellow materials and an original modeled double infrared sensor. Ten
frames per view (stand, rest, eight gait phases), with an independent head
layer for the compass pan command. WebP avoids a runtime 3D engine and model
download. The app uses canvas; the website uses SVG image viewports.

Source: PetoiCamp/ros_opencat, ros1 revision
85962928970ee47f38d53cad56f8e304863a87f5,
petoi_ROS_model_docs/bittle_ros/bittle_description.
Package MIT licence: copyright 2018 Toshinori Kitamura.
Repository MIT licence: copyright 2022 cc.
Both notices, source URLs, modifications and reproduction commands are in
static/bittle/NOTICE and the identical apps/web/public/bittle/NOTICE.
Petoi product photos were used as visual references only; none are shipped.

Sharing and size
Flybrain owns scripts/bittle-art/{fetch.py,render.py,sync.py}. The sync command
copies assets into the explicitly supplied Synaptix worktree and regenerates
a SHA-256/byte manifest. All six asset files match between repositories and
in the website production build. The common package totals 120,706 bytes;
the three compressed images total 114,002 bytes. The website loads only the
top/head images (60,584 bytes), after the existing lazy simulator opens.
The side image is retained in both copies to keep the distribution identical.
The guide embeds a compressed still and its licence so file:// and the
bundled guide both work offline. No simulation/model parameters changed.

Visual inspection
Headless Chromium: 390px and 1280px widths, light and dark, idle, approaches
from left/head-on/right, and escape. Inspected app scene and side canvases,
website SVG, compass at -45/0/+45 degrees, replay top view, and guide SVG.
Compared shell, head, servos and leg geometry to Petoi's product reference.
Enlarged the initial render in the scene/side view, aligned both beam roots
to the IR apertures, added a subtle dark-scene silhouette highlight, and moved
the website escape label below the feet. Stand/rest and articulated gait
were inspected; rest was a renderer fixture because escape controls do not
expose a rest command. Sensor beams, hand and band remain visible.

The replay top view test used one recorded mock frame with its simulator
field removed. Delaying image responses by 900ms exposed an initial-load
blank canvas, fixed by a load event that schedules redraw. All four
width/theme combinations then rendered correctly without another SSE frame.
Reduced-motion check kept the added gait at the standing frame. With all
non-local hosts blocked, the additional browser check recorded no external
requests and no JavaScript errors. No robot artwork was requested before
opening the website simulator.

Limits
The published generic Bittle shell represents the Bittle X exterior; internal
X electronics and exact accessory dimensions are not verified against
hardware. Gaits illustrate existing simulation phase/countdown, not measured
servo angles. Compass head pan rotates the rendered head in its image plane.
The desktop browser automation connection timed out, so UI inspection used
headless Chromium. The native app was built/smoke-tested, but its WebKit
window was not visually inspected. No hardware, Bluetooth, serial connection,
flashing, push, merge or branch switch occurred. Port 5199 was occupied;
the website worktree preview used 5209. The final commits remain local.
